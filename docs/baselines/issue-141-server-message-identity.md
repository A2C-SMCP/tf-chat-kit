## 可审查实现

- Protocol 的可选 `Message.serverMessageId` 与发送回执身份是 Server 中立字段；
  `outgoingMessages` 独立于正式时间线，复用现有 React 快照入口。
- Gateway 映射用户消息/POST 的 `elementId`，按会话关联正式身份、历史数据库别名与显示 ID。
  正式标识分支不按作者、正文或时间戳猜测；无标识保留 #136 的 current-server 兼容。
- Runtime 合并实时、历史及缓存中的身份；历史作者优先。只有数据库 ID 才产生持久化证据；
  稳定身份不提升 current-server 的恢复完整性。缓存内部完整别名冲突被拒绝；
  缓存与网络事实冲突时记录 `invalid-record` 并采用网络数据，订阅交接在状态准备后提交。
- 发送展示为 sending / accepted / failed / unknown；POST 身份只确认已接收，
  完整非缓存消息到达后收束。无 ID 的旧响应成功即撤除发送记录。
  欢迎页及会话均展示状态，可移除已结束记录，无自动重试、无缓存请求或重放。
- 新 Changeset 为公共身份及发送能力安排 minor；不改认证版本，不在本轮发布。
