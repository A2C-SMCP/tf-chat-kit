交互规则

首次接入时自动通过

目录确认加载完整后，只剩一个可用机器人或平台就自动选中。搜索后只剩一项时仍由用户点选。

卡片点击即提交

选机器人后加载它的平台，选平台后进入聊天。已有草稿或生成中的回复时，切换仍提示影响。

返回后停在选择页

返回最近可改选的一步，加载中也可返回。全程自动通过时，返回机器人列表并停留，等用户操作。

正式接入时的边界

方案落在可选的 ManagerChatApp。组织沿用已登录身份或 AuthClient 的候选账户。机器人沿用目录资格和分页状态，平台沿用当前机器人的服务端目录。宿主指定的平台继续优先并校验有效性。

主动切换保留选择页，用户返回时继续使用原聊天。点当前项直接返回。提交新选择时沿用现有实例释放和身份隔离。返回取消当前候选请求，忽略迟到结果。目录为空时显示空态，加载失败时提供重试。

ADR-014 与 ADR-015 的平台选择规则已由 ADR-021 补充。首次接入可以自动选中唯一有效平台。
