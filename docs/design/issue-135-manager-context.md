# #135 登录与工作上下文 UI

## 已批准范围

用户批准默认 UI 交互方案与可点击原型后要求实施。范围为 IN：`chat-kit/manager-antd` 依 ADR-015 组合现有公开客户端；不改变认证存储、传输 DTO、核心状态机或宿主生命周期，不需要新增 ADR。仅增强成品 UI，保留独立 Auth UI 和 Headless 消费路径。

## 页面

- 登录：品牌、环境、明确账号／密码输入，保留安全错误文案与登录过期恢复。
- 首次选择：组织 → 机器人 → 平台步骤，候选卡片及独立确认按钮；单项不自动选择。
- 设置：登录身份、当前工作组织、当前机器人／平台、帮助／退出分组；当前值与明确切换按钮并列。
- 聊天：工作组织入口、机器人入口、平台值与切换入口，环境单独标记。
- 切换：标记当前生效项，候选选中态与当前值分离。浏览、返回、加载失败不释放活动聊天；提交时执行草稿／运行中确认。

## 字段真实性

`AccountOption.displayName` 由 `displayName/accountName/name/username` 映射而来，不能可靠推断组织名或用户姓名。已核实 Manager `internal/user/api/dto/auth_dto.go`、`account_dto.go`、`user_dto.go`：选择列表、账户列表、切换与 `/me` 已提供独立 `organizationName`。auth 增加可选同名字段并仅映射该字段；不由账户名或登录输入构造。设置／聊天／选择页共用该组织标签，缺失时标记组织 ID／账户 ID，账户展示名称始终标为“账户名称”；登录身份只展示公开快照中的用户 ID。该可选字段是 auth 的独立 Minor 变更，不改变身份 scope 或凭据持久化记录。

平台名称来自 Server 平台目录；缺失时标记平台 ID。宿主指定平台一直可查看，切换入口隐藏并标记“由宿主指定”。

## 验证

从独立 tarball 消费者运行真实本地 HTTPS／HTTP／Socket.IO 流程，覆盖中文／英文、StrictMode、登录、首次选择、发送回复、历史、401／403、组织隔离、候选加载失败／取消、平台提交与固定平台、320／380／480／760px 和长名称。截图与结果记录在 `docs/baselines/issue-135-manager-context.md`。真实 Office WebView 验收单独记录，不用浏览器任务窗格模拟替代。
