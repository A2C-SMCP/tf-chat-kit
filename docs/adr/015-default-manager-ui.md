# ADR-015：可选完整 Manager 聊天 UI

- 状态：Accepted
- 日期：2026-10-13
- 关联：#129
- 授权：用户评审默认 UI 设计说明与可点击原型后确认“可以 就按这个来修改”。
- 补充并局部替代：ADR-010、012、013、014 中必须由宿主编排全部页面的限制。

## 决策

新增显式 `chat-kit/manager-antd` 入口，提供 ManagerChatApp 成品组合 UI。
该入口可以组合认证、Manager 目录/连接控制器与通用聊天 UI，并管理组件内部页面导航。
门面仍不得重写认证/聊天状态机、处理传输 DTO 或初始化全局实例。
没有新增包或叶子反向依赖；Headless 和现有默认导出不初始化此可选 UI。

宿主注入 AuthClient、ManagerClient 和稳定的连接配置；凭据持久化、可信服务地址、平台预设、
Word API、窗口隐藏及卸载策略仍由宿主拥有。UI 只通过公开客户端与 hooks 发出操作。
组件拥有自己创建的 ManagerChatController，卸载释放它，不释放宿主注入的认证/目录客户端。

新完整 UI 默认中文、浅色绿色主题与紧凑单列视图；已有独立组件的默认文案和布局保持兼容。
会话/设置面板不拥有聊天客户端的生命周期。身份变化立即遮蔽旧数据并使在途操作失效。
平台由宿主明确配置或用户确认，不自动创建或任意选择第一项。

## 验证

从打包产物验证完整流程，覆盖真实本地 HTTP/Socket、身份隔离、StrictMode、异常恢复、
320/380/480/760 容器。真实 Word 与 test 集群结果独立报告，原型不构成生产验收。
