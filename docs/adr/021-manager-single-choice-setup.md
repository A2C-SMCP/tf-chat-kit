# ADR-021 / ManagerChatApp 首次接入的唯一选项与返回

- 状态：Accepted
- 日期：2026-11-26
- 授权：用户确认[可点击原型](../design/manager-selection-demo.html)并要求按方案修改。

## 决策

- 可选 `ManagerChatApp` 的首次接入允许自动选中唯一有效项。已认证时直接使用当前账户。认证要求选择账户且只提供一个候选时，通过 AuthClient 完成选择。
- 机器人目录成功加载完整且只有一项可连接时，自动进入该机器人的下一步。部分目录、搜索结果和主动切换页面等用户点选。
- 对支持平台选择的接入，只有当前机器人的平台目录成功加载且恰好有一个有效平台时，才自动提交平台。宿主预设优先，仍走原有目录校验。此项扩展 ADR-014 和 ADR-015 的平台选择规则，其他入口继续使用各自的显式选择契约。
- 有多个选项时，点选卡片即提交该步骤。已有草稿或生成中的回复时，切换工作空间继续使用原有影响确认。
- 正在加载平台或打开聊天时也可以返回。返回取消候选请求并使迟到结果失效。聊天中可返回最近可改选的一步，全自动路径回到机器人列表供用户操作。浏览候选期间保留当前工作空间，提交新上下文才释放旧连接。

## 验证

打包消费者覆盖唯一可连接机器人与平台、直接点选、加载中返回、空平台目录、当前项复选和取消切换。实例、权限及凭据边界沿用 ADR-012 至 ADR-015。
